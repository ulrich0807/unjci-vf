# UNJCI — interface Angular

Ce frontend utilise l’API Laravel de gestion des adhésions et renouvellements.
La documentation à jour (installation, tests, configuration Wave, fichiers privés et déploiement) se trouve dans [le README principal](../README.md).

Les commandes sont : npm start, npm test -- --watch=false et npm run build.
Le proxy de développement cible Laravel sur http://127.0.0.1:8000.
