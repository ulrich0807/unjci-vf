# UNJCI — API Laravel

Cette API gère les adhésions, renouvellements, pièces justificatives, paiements Wave, cartes QR et permissions administratives.
Consulter [la documentation principale](../README.md) pour la configuration, les tests et les règles de déploiement.

Les secrets sont configurés dans .env, jamais dans .env.example.
Les nouveaux fichiers sont stockés sur le disque privé ; leur lecture nécessite une authentification et un contrôle d’accès.
